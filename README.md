# Pixi.js to Skia Bridge & Vector PDF Exporter

Инженерный прототип графического моста, объединяющий возможности игрового движка **Pixi.js (v7 Legacy Canvas)** и нативного 2D-движка **Skia (Google CanvasKit WASM)**. Приложение реализует сквозную синхронизацию графа сцены (Scenegraph), интерактивность событий на изолированных холстах и экспорт графики в честный векторный PDF полиграфического качества.

## Бизнес-ценность проекта (Proof of Concept)
Исторически рендереры браузерных движков (Pixi/Three.js) генерируют растровые изображения. При попытке экспортировать сцену в PDF, графика превращается в растр, который пикселизируется при масштабировании, что неприемлемо для чертежей, графиков и полиграфии.

Данный проект решает эту проблему:
1. **Интерфейс и анимация** работают на высокопроизводительном холсте в браузере (Pixi).
2. **Экспорт сцены** транслируется в нативный C++ движок Skia, который формирует идеальный векторный PDF-файл.

## ️ Архитектура и Структура проекта

Проект реализован по принципам **Чистой Архитектуры (Clean Architecture)** с соблюдением инверсии зависимостей. Слои полностью изолированы, код строго типизирован без использования типа `any` (соблюдено правило `no-explicit-any`).

### Направление зависимостей (Схема)
`Presentation (UI)` ➔ `Use Cases (Бизнес-логика)` ➔ `Domain (Интерфейсы)` 📥 `Infrastructure (Адаптеры Pixi/Skia)`

### Ключевые паттерны
*   **Visitor (Рекурсивный маппер):** Реализован внутри `SkiaRenderer`. Обходит граф сцены Pixi, извлекает матрицы трансформаций (сдвиг, поворот, масштаб), аккумулирует прозрачность (`accumulatedAlpha`) и переводит в нативные команды Skia Canvas.
*   **Event Bridge (Математический мост событий):** Холст Skia не имеет своего дерева объектов и является «слепым» пиксельным буфером. Мост событий перехватывает клики и движения мыши на холсте Skia, пересчитывает экранные координаты с учетом масштабирования CSS в физическую сетку `500x500` и запускает кастомный математический хит-тест (инверсия матриц трансформаций) по графу сцены Pixi.

## Технологический стек
*   **Сборщик:** Vite + TypeScript (Modern ESM)
*   **Среда тестирования:** Jest + `ts-jest` + `jest-canvas-mock` (Тестирование по методологии TDD)
*   **Графика:** `pixi.js-legacy` (v7.2.4, принудительный Canvas-рендер `forceCanvas: true`)
*   **WASM:** `canvaskit-wasm` (Кастомная полная сборка с поддержкой PDF-бэкенда)

## Быстрый запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера разработки (Vite)
```bash
npm run dev
```
Приложение откроется локально по адресу: `http://localhost:3000`

### 3. Запуск тестов (TDD / Jest)
Тесты проверяют бизнес-логику добавления фигур (Use Cases) и математику маппинга матриц трансформаций в полной изоляции от браузера.
```bash
npm run test
```

## Ручная компиляция Skia WASM (PDF Backend)

Стандартный npm-пакет `canvaskit-wasm` поставляется разработчиками Google без поддержки экспорта в PDF ради уменьшения веса файла (2.5 МБ против ~10 МБ). В данном проекте осуществлена **ручная сборка WebAssembly модуля Skia из исходников** с флагом `enable_pdf`.

## Критерии готовности ТЗ
- [x] Обертка для Skia принимает `PIXI.Container` со всеми вложенными детьми.
- [x] Поддерживаются трансформации: сдвиг (translate), поворот (rotate), масштабирование (scale).
- [x] Реализован рендер сложных путей (`PIXI.Graphics`: `moveTo`, `lineTo`, `drawRect`, `drawPolygon`, линии, обводки и заливки).
- [x] Реализован экспорт сцены в **векторный PDF файл** через нативный метод Skia `GeneratePDFBase64`.
- [x] Синхронизированы события `pointerDown` и `pointerUp` на обоих холстах.
- [x] Реализован интерактивный визуальный отклик (блекние `alpha = 0.5` при клике и возвращение цвета) на обоих холстах синхронно.
- [x] Реализовано динамическое изменение курсора мыши (`cursor: pointer`) при наведении на фигуры на холсте Skia на основе инвертированных матриц.
- [x] Интерфейс разделен на две независимые панели для визуального сравнения точности рендеринга пиксель-в-пиксель.
- [x] Код полностью декомпозирован, покрыт комментариями и юнит-тестами Jest.
